## Overview
Users can add products to a basket. Products are automatically grouped by store, creating one basket per store. The feature compares the total price of the different store baskets side by side.

## Product Selection
- Users manually select products from the existing product list and search
- No automatic cross-store product matching needed — users pick what they want to compare

## UI Flow
1. **Product list/search**: Add a button (e.g. "Add to basket") on each product in the existing product list
2. **Compare button**: Visible when the basket is non-empty; opens a dedicated comparison page or modal
3. **Comparison view**: Shows baskets grouped by store with individual product prices and a total per store. Highlights the cheapest basket. Includes price history charts for the selected products across stores.

## Persistence & Sharing
- Baskets are stored locally in the browser (localStorage)
- Baskets are exportable/shareable via a static URL using the `#` fragment (so the link works without a server)

## Price History
- The comparison view includes price history over time for each product in the basket
- Show how each store's prices evolved on charts

## Location
- Entirely in the `dashboard/` static frontend (HTML/CSS/JS)
- No backend changes needed

## Scope
Full-featured implementation as described above (not a minimal MVP).
