## Problem

The velofood.at site has been rebranded to **Ninjas Market** and moved its product listing from 
WooCommerce category pages (`/produktkategorie/supermarkt/`) to a custom SPA at `/market`.

The old HTML scraper was:
- Scraping paginated WooCommerce HTML at `/produktkategorie/supermarkt/page/N/`
- Parsing `li.product` elements with CSS selectors
- Extracting prices from `.woocommerce-Price-amount` elements
- Guessing product IDs from `data-product_id` attributes

This approach was **broken** because the shop no longer serves products at those URLs.

## Investigation (https://velofood.at/market)

Explored the `/market` page and discovered:

1. **New custom JSON API** — products are loaded via AJAX, no more server-rendered HTML
2. **Two equivalent API endpoints** (both unauthenticated, GET):
   - `GET /wp-json/velofood/v1/market_get_products?cat_id=<id>&level=0&sort=default`
   - `GET /custom_api/vfapi.php?action=market_get_products&cat_id=<id>&level=0&sort=default`
3. **15 top-level categories** with ~80 subcategories, embedded as inline JSON in the page
4. **Structured product data** with `price_sort` (float), `measure` (e.g. "300g"), `biolabel` array
5. Using `level=0` returns all subcategories for a parent category in one request

## Changes Made

### `dashboard/velofood-api.md`
- Complete rewrite documenting the new JSON API
- Full response schema, category list, parsing rules
- Deprecated old HTML scraping notes

### `data-collector/stores/velofood.js`
- Replaced HTML scraping with direct JSON API calls
- Iterates 15 top-level categories with `level=0` to fetch all ~1,500 products
- Uses `price_sort` (float) instead of parsing price strings from HTML
- Parses structured `measure` field (e.g. "300g", "1l", "6stk") instead of regex on product names
- Uses `biolabel` array for bio detection (falls back to name check)
- Deduplicates by product ID across categories
- Skips out-of-stock items

## Verification

Successfully tested: **1473 products** fetched in ~24s with proper unit conversion:
- `g`: 767 items, `ml`: 536 items, `stk`: 170 items
- 176 bio items detected
- Zero parse errors
